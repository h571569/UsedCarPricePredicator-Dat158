# UsedCarPricePredicator - Dat158

Used car price prediction project for DAT158.

The project currently contains car datasets and Python data preparation code using pandas.

- `data/cars.csv`: original car dataset.
- `data/cars_cleaned.csv`: cleaned car dataset.
- `data_cleaning.py`: data preparation functions, including translation of Cyrillic car and model names.

## Setup

```sh
python -m venv .venv
source .venv/bin/activate
pip install pandas
```
